# Lumos

**Lumos** is a full-stack web application designed to empower users through personalized insights and tools. This project integrates a React frontend, Node.js/Express backend, and modular architecture for scalability and maintainability.

---

## 🚀 Features

* **Frontend:** Built with React + TypeScript + TailwindCSS
* **Backend:** Node.js + Express + MongoDB
* **Authentication:** Google OAuth integration
* **Dashboard:** Interactive UI for managing user data and reports
* **AI/ML Integration (sona-bright-mind):** Predictive module for intelligent recommendations
* **Optimized Builds:** Configured with Vite for fast development and production builds

---

## ⚙️ Installation & Setup

1. **Clone the repository**

   ```bash
   git clone https://github.com/gunjan-chandnani/lumos.git
   cd lumos
   ```

2. **Install dependencies**

   ```bash
   npm install
   ```

3. **Set up environment variables**

   * Create a `.env` file and add required API keys or database URLs.
   * Example:

     ```bash
     MONGO_URI=your_mongodb_url
     GOOGLE_CLIENT_ID=your_google_client_id
     GOOGLE_CLIENT_SECRET=your_google_client_secret
     ```

4. **Run the development server**

   ```bash
   npm run dev
   ```

5. **Build for production**

   ```bash
   npm run build
   ```
